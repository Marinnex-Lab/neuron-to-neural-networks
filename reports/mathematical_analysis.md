# Mathematical analysis

This report collects the mathematical claims made in the repository. Each claim is labelled as one of:

- **Proof**: derived in full in the repository.
- **Theoretical result**: a known result, stated with its assumptions and not re-derived here.
- **Experimental observation**: a number produced by a script in this repository, under the settings listed.
- **Engineering trade-off**: a practical consequence, not a theorem.

Numbers are copied from `reports/*.md` and `results/*.json`, which are generated by the scripts.

## 1. The neuron and the layer

**Proof.** A layer of $m$ neurons with weight matrix $W\in\mathbb{R}^{n\times m}$ computes $Z = XW + \mathbf{b}$ for a batch $X\in\mathbb{R}^{N\times n}$. Each entry $Z_{sj} = \sum_i X_{si}W_{ij} + b_j$ is the weighted sum of neuron $j$ on sample $s$.

**Proof (collapse).** For two linear layers without activation, $(XW_1+\mathbf{b}_1)W_2+\mathbf{b}_2 = X(W_1W_2)+(\mathbf{b}_1W_2+\mathbf{b}_2)$. This is one linear layer. A nonlinearity between the layers prevents this equivalence in general.

**Experimental observation.** In `notebooks/05_forward_propagation.ipynb`, with the example weights, the two-layer output is $(5.7, -0.2)$ and the collapsed output is the same. With a ReLU in between, the output is $(5.5, 0)$.

## 2. Linear separability and XOR

**Proof (XOR is not linearly separable).** Suppose $w_1, w_2, b$ separate XOR. The four conditions are $b<0$, $w_2+b\ge 0$, $w_1+b\ge 0$, and $w_1+w_2+b<0$. Adding the second and third gives $w_1+w_2+2b\ge 0$. The fourth gives $w_1+w_2<-b$, so $w_1+w_2+2b<b$. Together $0\le w_1+w_2+2b<b$, which forces $b>0$. This contradicts $b<0$. No such weights exist.

**Proof (AND and OR are separable).** $\mathbf{w}=(1,1)$, $b=-1.5$ separates AND; $\mathbf{w}=(1,1)$, $b=-0.5$ separates OR.

**Experimental observation** (`results/logic_gates.json`, learning rate 0.1, 20 epochs, zero initialization):

| Gate | Accuracy | Mistakes in epoch 1 | Mistakes in epoch 20 |
|---|---|---|---|
| AND | 100% | 2 | 0 |
| OR | 100% | 2 | 0 |
| XOR | 50% | 3 | 4 |

**Theoretical result (perceptron convergence).** For linearly separable data, the perceptron rule makes a finite number of mistakes (Novikoff, 1962). The XOR result above is consistent with this, because XOR is not separable.

## 3. Learning rate with zero initialization

**Proof (exact arithmetic).** With zero initialization and integer-valued inputs, each update adds $\eta\cdot\text{error}\cdot\mathbf{x}$ and $\eta\cdot\text{error}$. The weights and bias are therefore $\eta$ times an integer vector and an integer. The sign of $z$, and so every prediction, does not depend on $\eta>0$.

**Experimental observation** (`notebooks/03`, `tests/test_perceptron.py`). With the exact binary rates $0.5$ and $1.0$, the mistake sequences are identical: 2, 3, 3, 2, 1, 0. With $\eta=0.1$, rounding at the point $(1,0)$ (where the exact value is $z=0$) changes one decision, so the sequence is 2, 3, 3, 0, 0, 0.

**Engineering trade-off.** When a prediction lies exactly on the boundary, rounding can decide it. Tests that compare learning rates should use exact binary values or tolerances.

## 4. Gradients

**Proof (BCE with sigmoid).** For $p=\sigma(z)$ and $\ell=-[y\log p+(1-y)\log(1-p)]$, the chain rule gives $\partial\ell/\partial z = p-y$.

**Proof (backpropagation for the two-layer network).** The equations in `src/mlp.py` follow from the chain rule applied to $z^{(2)}=hW^{(2)}+b^{(2)}$, $h=\sigma(z^{(1)})$ and $z^{(1)}=xW^{(1)}+b^{(1)}$. The matrix form is $dZ_2=(\hat Y-\mathbf{y})/N$, $dW_2=H^\top dZ_2$, $dH=dZ_2W_2^\top$, $dZ_1=dH\odot H\odot(1-H)$, $dW_1=X^\top dZ_1$.

**Experimental observation.** Analytic gradients agree with central finite differences to about $10^{-10}$ (`notebooks/08`, `notebooks/09`, `tests/test_mlp.py`, `tests/test_multilayer_batch.py`). The matrix form equals the per-sample loop form exactly in the notebook check.

**Proof (vanishing bound).** $\sigma'(z)\le 0.25$ for all $z$. A product of $L$ sigmoid derivatives is therefore at most $0.25^L$. For $L=10$ the bound is $9.54\times10^{-7}$.

## 5. Optimizers on $f(w)=w^2$

**Proof.** Gradient descent gives $w_{t+1}=(1-2\eta)w_t$. It converges if and only if $0<\eta<1$.

**Proof (Adam, first step).** With $g$ constant, bias correction gives $\hat m_1=g$ and $\hat v_1=g^2$, so the first step has size $\eta$.

**Experimental observation** (`notebooks/07`, `tests/test_optimizers.py`). Starting at $w_0=1$ with $\eta=0.1$: GD gives $0.8, 0.64, 0.512$; momentum gives $0.8, 0.46, 0.062$; RMSProp gives $0.6838, 0.4989, 0.3692$; Adam gives $0.9, 0.8004, 0.7016$.

**Theoretical result (Adam).** Adam is not guaranteed to converge on all convex problems (Reddi, Kale and Kumar, 2018). This repository does not test that claim.

## 6. Multilayer network on XOR

**Experimental observation** (`results/multilayer_xor.json`, learning rate 0.5, 3000 full-batch steps, seeds 0 to 19, sigmoid units, BCE):

| Hidden units | Runs solving XOR | Median final loss |
|---|---|---|
| 2 | 16 / 20 | 0.0135 |
| 3 | 20 / 20 | 0.0106 |
| 4 | 20 / 20 | 0.0087 |

**Interpretation.** A hidden layer solves a task that one perceptron cannot. Whether a given random start succeeds depends on the initialization. These results are for XOR only, and they do not establish success rates for other tasks.

## 7. Learning rate on a held-out split

**Experimental observation** (`results/learning_rate_study.json`, circle task, 120 training and 120 validation points, architecture 2 → 4 → 1, 1500 steps, seeds 0 to 4):

| Learning rate | Mean training loss | Mean validation loss | Diverged runs |
|---|---|---|---|
| 0.05 | 0.6235 | 0.6365 | 0 / 5 |
| 0.2 | 0.5761 | 0.5966 | 0 / 5 |
| 0.5 | 0.3527 | 0.4261 | 0 / 5 |
| 2.0 | 0.2202 | 0.3519 | 0 / 5 |
| 8.0 | 0.2124 | 0.3944 | 0 / 5 |

**Interpretation.** At 0.05 the training loss is still high after 1500 steps, so that setting has not converged in this budget. The decision rule chose 2.0. A different budget could change the choice. Five seeds give a rough spread, not a confidence interval.

## 8. Attention and the transformer block

**Proof (softmax row sums).** Each row of $\text{softmax}(S)$ sums to 1 by construction, so the attention output for token $i$ is a weighted average of value vectors.

**Proof (causal mask).** Setting future scores to $-\infty$ gives them zero weight after the softmax, so token $i$ depends only on tokens $j\le i$.

**Experimental observation** (`tests/test_transformer.py`, `notebooks/11`). The example weights, scores, output and block output match the hand calculations in the notes. The residual block output $(1.14, 0.19, 1.02, 0.10)$ is exact to $4\times10^{-6}$; the difference comes from the layer-normalization epsilon.

**Engineering trade-off.** Attention cost grows with the square of the sequence length, while feed-forward cost grows linearly. This is why long contexts are expensive. The repository does not measure runtime.

## 9. Limits of this analysis

- All experiments use small synthetic data and few seeds. They illustrate mechanisms; they do not benchmark models.
- No timing or memory measurements are reported.
- The step budgets are fixed. Conclusions about convergence speed apply only to those budgets.
- Theoretical results are cited, not re-derived, except where a short proof is given above.
